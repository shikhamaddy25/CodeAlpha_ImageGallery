# Wanderlust - Image Gallery

A responsive image gallery created as part of my CodeAlpha Frontend Development Internship.

## Features
- Responsive image gallery
- Smooth hover effects and transitions
- Full-screen image lightbox
- Next and Previous image navigation
- Keyboard navigation using arrow keys
- Close lightbox using the Escape key

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` - Gallery structure
- `style.css` - Styling and responsive design
- `script.js` - Lightbox and image navigation
- `images/` - Gallery images

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click any image to open the lightbox.
